Files & Folders

✓ Completed

Almost every VA task involves a file: a document to edit, a photo to rename, a spreadsheet to update, a PDF to send.

A VA who can find, name and organize files quickly saves time every day, and looks professional doing it. This lesson covers the file skills you'll use most.

Files, Folders and Where They Live

A file is one item: a document, a photo, a spreadsheet. A folder holds files, and can hold other folders too.

You open and manage your files in File Explorer on Windows (the yellow folder icon on the taskbar) or Finder on a Mac (the blue face icon in the Dock). Both come with the same main folders:

  • Desktop: files shown on your main screen
  • Documents: a general place for your work files
  • Downloads: where files from the internet usually land
  • Pictures: photos and, on Windows, screenshots

A simple habit that helps: make one folder for your VA work, then one folder inside it for each client or project. Don't leave work files scattered across the Desktop and Downloads.

Everyday File Actions

You'll find almost all of these by right-clicking a file or folder.

ActionWhat it does
New folderRight-click an empty space in a folder window and choose New › Folder (Windows) or New Folder (Mac).
RenameChanges a file's or folder's name.
Save / Save AsSave keeps your changes in the same file. Save As creates a new copy with a new name or location, and leaves the original as it was.
DeleteSends the file to the Recycle Bin (Windows) or Trash (Mac). It isn't gone yet.
RestoreBrings a deleted file back from the Recycle Bin or Trash, as long as it hasn't been emptied.

Copy or Move?

This is the difference beginners mix up most often. Try both buttons and watch what happens to each folder.

Folder A
Folder B

Copy when the original must stay where it is, for example keeping a client's original photos untouched while you work on duplicates. Move when you're putting a file in its proper place, and don't need it in the old one.

To copy, right-click the file, choose Copy, open the other folder, right-click an empty space and choose Paste. To move, use Cut instead of Copy, or drag the file into the other folder.

Naming Files So People Can Find Them

A good file name tells anyone what the file is without opening it. Compare:

Hard to useEasy to use
IMG_2931.jpgblue-mug-front.jpg
final final v2.docxprice-list-2026-09-v2.docx
Document1.pdfinvoice-rivera-2026-09-15.pdf

A few simple rules:

  • Say what the file is, and who or what it's for.
  • Write dates as year-month-day (2026-09-15), so files sort in the right order.
  • Use hyphens instead of spaces or odd symbols.
  • If the client already uses a naming style, follow theirs.
  • Keep the dot and the letters after it (like .pdf) unchanged when you rename.

File Types You'll See

The letters after the dot are the file extension. They tell the computer, and you, what kind of file it is.

ExtensionWhat it usually is
.pdfA document meant to be read, printed or signed, not easily edited
.docxA Word document
.xlsxAn Excel spreadsheet
.csvPlain spreadsheet data, often exported from another system
.jpg / .pngImages. Screenshots are often .png
.zipA bundle of files packed into one (Lesson 4 shows how to open it)

Windows hides extensions by default. To show them, open File Explorer, choose View › Show, and tick File name extensions. (On Windows 10, it's a tick box on the View tab.) On a Mac, open Finder, choose Finder › Settings › Advanced, and tick Show all filename extensions.

When You Can't Find a File

"Where did my file go?" happens to everyone. Before you panic, go through these in order:

  1. Check Downloads if the file came from the internet or an email.
  2. Search. Type part of the file name into the search box in File Explorer or Finder, or in the Start menu (Windows) or Spotlight, ⌘ + Space (Mac).
  3. Sort by date. In a folder, sort by Date modified so your newest files appear at the top.
  4. Check recent files. File Explorer's Home page and Finder's Recents list show files you opened lately.
  5. Check the Recycle Bin or Trash in case it was deleted by mistake.

Key Takeaway
  • Keep work files in organized folders, not scattered across your Desktop and Downloads.
  • Copy keeps the original in place. Move takes it away from the old place.
  • Name files so anyone can tell what they are without opening them.
  • Can't find a file? Check Downloads, search, sort by date, check recent files, then check the Recycle Bin or Trash.
